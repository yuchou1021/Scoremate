# 谱伴 ScoreMate —— 用户装机指引（约 1 小时）

> 你不需要会编程、不需要学 QML。本指引只教你 4 个操作：**装软件、装插件、
> 运行插件、看报错**。全部做完，AI 改编助手就能在你电脑上跑起来。

---

## 第 1 步：安装 MuseScore 4（约 10 分钟）

1. 打开 <https://musescore.org/zh-hans/download>，下载 **MuseScore Studio 4**（最新 4.x 版本）
2. 安装后启动，会看到空白的乐谱编辑器界面
3. 认识一下界面：左上"文件"菜单、中间的五线谱编辑区、右边的乐谱面板
4. 找一个谱子试试：菜单 **文件 → 打开**，选任意 `.mscz`/`.mscx`/`.xml` 文件；
   没有谱子的话，菜单 **文件 → 新建** 建一张空谱（选钢琴）随便点几个音符

✅ 验收：你能打开/新建一份乐谱，并能在五线谱上看到音符

---

## 第 2 步：认识插件的三个操作（约 15 分钟）

MuseScore 插件 = 一段可以扩展软件功能的小程序，放在特定文件夹里即可被识别。

**操作 A：找插件目录**（官方默认路径，也可在 偏好设置 → 文件夹 里改）
- Windows：`C:\Users\<你的用户名>\Documents\MuseScore4\Plugins\`
- macOS：访达 → 前往 → 前往文件夹 → `~/Documents/MuseScore4/Plugins`
- Linux：`~/Documents/MuseScore4/Plugins`

（如果目录不存在，先打开一次 MuseScore 再关闭，软件会自动创建）

**操作 B：启用插件**
MuseScore 菜单 → **插件(Plugins) → 插件管理器(Plugin Manager)**，勾选你想启用的插件

**操作 C：运行插件**
MuseScore 菜单 → **插件 → 插件名**。插件出错了会弹错误对话框，或把错误显示在插件管理器里

✅ 验收：你能说清楚"插件目录在哪、怎么启用、怎么运行"三件事

---

## 第 3 步：跑通一个官方示例插件（约 15 分钟）

1. 打开插件管理器，看自带的插件列表（不同版本自带插件不同，常见有
   **Color Notes**（音符染色）、**Hello World** 等）
2. 勾选启用其中一个，选中一小段音符，菜单里运行它
3. 观察效果：Color Notes 会给音符染色，Hello World 会弹一个对话框

✅ 验收：示例插件成功运行。**这一步通过 = 插件机制在你的电脑上完全可行**

> 💡 这就是项目可行性验证的核心一步：只要能运行插件，我们的 AI 插件就一定能装上跑起来。

---

## 第 4 步：导入一首想改编的谱子（约 10 分钟）

1. 找一首你想"改简单"或"转调"的曲子（自己的原创、公有领域谱都行；版权谱仅限自用）
2. 拖进 MuseScore，或 文件 → 打开
3. 练习操作：**选中一段**（点第一个音符，按住 Shift 点最后一个音符）、
   **全选**（Ctrl+A）、播放（空格键）

✅ 验收：你能选中任意一小节区间，并知道"选区"是什么

---

## 第 5 步：准备 LLM API Key（可后补，v0.2 才需要）

> v0.1 的转调/简化是纯规则引擎，**不需要** API Key 就能用。
> v0.2 的"局部和弦重配/加花"才需要。现在可以先不弄，知道有这回事即可。

- 主流选择：DeepSeek 开放平台 <https://platform.deepseek.com/>（注册 → 充值少量 → 创建 API Key）
- 或任何 OpenAI 兼容服务（通义、智谱、Ollama 本地等），到时候填 Base URL + Key + 模型名就行

✅ 验收（可跳过）：你有一个 API Key 的存放位置（先记在备忘录里即可）

---

## 第 6 步（可选）：先跑起来看看云端服务长什么样（约 20 分钟）

不装也能等插件做好；想提前看看服务端效果可以试：

```powershell
cd server
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

浏览器打开 <http://127.0.0.1:8000/api/health>，看到 `{"status":"ok",...}` 就成功了。
可以再试试分析接口（PowerShell）：

```powershell
$body = '{"notes":[60,62,64,65,67,69,71,72],"measures":2}'
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/api/analyze -ContentType 'application/json' -Body $body | ConvertTo-Json
```

应该能看到调性检测结果（C 大调音阶 → 大概率返回 `C major`）。

✅ 验收：`/api/health` 返回 ok

---

## 第 7 步：反馈格式（以后每次测试都用到）

插件报错或效果不对时，把下面三样发给我（AI）即可，不用你自己分析：

1. **报错文本**：错误对话框里的完整文字（截图也行）
2. **操作步骤**：你做了什么（哪首曲子、选了哪段、点了什么）
3. **预期 vs 实际**：你希望发生什么、实际发生了什么
